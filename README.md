# Reat Capital — Website Clone

A pixel-faithful clone of [reat.capital](https://reat.capital/) built with pure HTML, CSS, and vanilla JavaScript. No frameworks, no build tools — just open `index.html` in a browser.

## ✨ Features

- **Responsive navbar** with dropdown menus & mobile hamburger
- **Animated hero section** with particle canvas, counter animations & floating badges
- **Feature cards** with 3D tilt on hover
- **Seed Blocks** — Bronze / Silver / Gold / Diamond tiers
- **Benefits grid**, YouTube video section, FAQ accordion
- **Contact form** with validation
- **Scroll-reveal animations** (pure IntersectionObserver — no library)
- **Dark premium design** with glassmorphism, gradients & micro-animations

## 🚀 Quick Start

Just open `index.html` — no build step required.

```bash
# Optional: serve locally
npx serve .
```
